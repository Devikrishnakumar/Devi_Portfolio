# Devi Krishnakumar — Placement Portfolio

A responsive, terminal-inspired portfolio website for a B.E. CSE (Cyber Security) student interested in DevOps, cybersecurity and DevSecOps.

## Built with
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Website sections
- Introduction and education
- About and career goal
- Technical skills and tools
- Selected hands-on projects
- Contact links

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish and open the URL shown on the Pages settings screen.

## Before publishing
- Replace the placeholder email address in `index.html` with your professional email.
- Replace the LinkedIn placeholder URL with your actual profile URL.
- Add a professional photo if desired. The current design does not require a photo.
- Check that every project repository link is public and accurate.
- Only list tools and skills you can confidently discuss in an interview.

## Updating the site
Edit the files, then run `git add .`, `git commit -m "Update portfolio"`, and `git push`. GitHub Pages will publish the changes after its deployment completes.
